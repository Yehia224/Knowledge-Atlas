# Book intake

No book has been received or registered in this change. Use index.json for bibliographic records, and the source-record template in the parent directory.

For each edition, record author(s), full title, publisher, edition/year, ISBN, official URL, table-of-contents locator, permission/access and (when actual bytes are accessible) a SHA-256 digest. Different editions are distinct source versions.

For analysis: inventory chapters, map topics to existing concepts, identify missing concepts and prerequisites, extract claim-level evidence with chapter/page/section, record conflicting explanations, then queue subject review. Research outputs belong under research, not inside the book record. Do not equate coverage of a book with complete coverage of a discipline.

For privately supplied PDFs, store files in a private authorized workspace (or locally in an ignored directory), not this public repo. Public-domain or openly licensed originals may only be committed after verifying redistribution permissions and the project publication gate. Link to official copies otherwise. No full book redistribution by default.
