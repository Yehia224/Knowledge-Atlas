Information & Data Representation

قبل ما نتعلم أي لغة برمجة، محتاجين نفهم الكمبيوتر بيتعامل مع إيه أصلًا. هنبدأ بقراءة من Thermometer ونمشي وراها لحد ما تبقى موجودة جوه ملف.

01 / From observation to data

تخيل إنك قست درجة حرارة الميه، وظهر قدامك الرقم 20. هل الرقم لوحده كفاية عشان تفهم اللي حصل؟ لازم تعرف إنه قياس لدرجة الحرارة، وإن الوحدة Celsius، وإن القياس يخص الميه دي.

Value + unit + context
Data
A representation of values, observations or other content that can be stored or processed.
Information
Meaning obtained when data is interpreted in context.

هنا الـ Data هي القيمة والبيانات المصاحبة ليها. لما نفسرها ونفهم إنها درجة حرارة الميه، بنحصل على Information. الفرق ده تبسيط تعليمي، لأن استخدام المصطلحين بيختلف حسب المجال.

02 / How can a value be stored?

الكمبيوتر مش بيحتفظ بالرقم كرسمة على الشاشة بالضرورة. هو بيستخدم حالات مادية قابلة للتمييز لتمثيل البيانات. هنركز على أبسط وحدة من التمثيل الرقمي.

Bit
A binary digit with one of two possible values: 0 or 1.
Byte
A group of eight bits in modern computing.

TRY IT · UNSIGNED 8-BIT INTEGER

اضغط على أي Bit لتغييره. لاحظ إن مكانه بيحدد قيمته، مش مجرد عدد الـ 1s.

Decimal value: 20

في المثال ده اتفقنا إن الـ Byte يمثل عدد صحيح غير سالب. لو استخدمنا نفس الـ Bits مع قاعدة مختلفة، ممكن يكون ليها معنى تاني.

03 / Representation is a convention

خد الرقم 65 كمثال. ممكن نخزنه كعدد، وممكن نخزن حرف A. في UTF-8، الحرف A بيتمثل بنفس الـ Byte اللي قيمته العددية 65. اللي بيحدد المعنى هو طريقة تفسير البيانات.

BitsInterpretationResult
01000001Unsigned integer65
01000001UTF-8 textA
Encoding
A defined mapping between information and a representation. For example, UTF-8 maps Unicode code points to byte sequences.

مش كل حرف بياخد Byte واحد. UTF-8 ممكن يستخدم من واحد لأربعة Bytes لتمثيل Unicode code point واحد. هنفهم الفرق بين Code Point والحرف الظاهر في درس مستقل.

04 / From data to a file

File
A named collection of data managed by a file system.
File format
A defined structure and interpretation for data stored in a file.

لما تفتح PNG، البرنامج بيتبع قواعد الـ PNG عشان يفك البيانات ويعرض الصورة. أما SVG فبيقرأ وصف رسومات، زي دائرة أو خط. الاتنين ملفات، لكن طريقة تنظيم البيانات مختلفة.

عشان كده امتداد الملف مش هو اللي بيخلق الصورة أو المستند. البرنامج لازم يعرف قواعد الـ Format ويكون قادر يفسر البيانات اللي جواه.

05 / Check your understanding

حاول تجاوب قبل ما تفتح الإجابة.

هل الرقم 20 وحده يحدد درجة حرارة الماء؟

لأ، محتاج الوحدة وسياق القياس. 20 °C و20 K مش نفس درجة الحرارة.

What is the value of 00000101 as an unsigned integer?

5 (4 + 1).

هل تغيير امتداد ملف PNG إلى SVG بيحوله فعلًا؟

لأ. تغيير الاسم مش بيغير تنظيم البيانات داخل الملف.
